# J04008 - CHU VI TAM GIÁC

## Đề bài

Khai báo lớp `Point` (điểm trong không gian hai chiều) có mô tả như sau:

### 1. Lớp Point

**Thuộc tính:**

| Thuộc tính | Kiểu dữ liệu | Mô tả    |
| ---------- | ------------ | -------- |
| `- x`      | `double`     | Tọa độ x |
| `- y`      | `double`     | Tọa độ y |

**Phương thức:**

| Phương thức                      | Kiểu trả về | Mô tả                                                                   |
| -------------------------------- | ----------- | ----------------------------------------------------------------------- |
| `+ Point()`                      | Constructor | Tạo đối tượng mặc định                                                  |
| `+ Point(double x, double y)`    | Constructor | Tạo đối tượng có tọa độ trong tham số                                   |
| `+ Point(Point p)`               | Constructor | Tạo đối tượng là bản sao của đối tượng trong tham số                    |
| `+ getX()`                       | `double`    | Trả về tọa độ X                                                         |
| `+ getY()`                       | `double`    | Trả về tọa độ Y                                                         |
| `+ distance(Point secondPoint)`  | `double`    | Trả về khoảng cách từ điểm này tới điểm thứ hai                         |
| `+ distance(Point p1, Point p2)` | `double`    | Trả về khoảng cách giữa hai điểm (phương thức static)                   |
| `+ toString()`                   | `String`    | Chuyển một đối tượng về dạng xâu ký tự, ghi đè phương thức `toString()` |

**Chú thích:**

- `-` : Thuộc tính private.
- `+` : Phương thức public.
- `distance(Point p1, Point p2)` là phương thức static.

### 2. Yêu cầu

Viết chương trình nhập 3 điểm `p1`, `p2`, `p3`.

Hãy tính chu vi tam giác được tạo bởi 3 điểm đó.

## Input

- Dòng đầu ghi số bộ test, không quá 10.
- Mỗi bộ test ghi trên 1 dòng 6 số thực có giá trị tuyệt đối không quá 1000, lần lượt là tọa độ của 3 điểm.

## Output

- Nếu 3 điểm không thể tạo thành tam giác thì in ra `INVALID`.
- Nếu 3 điểm tạo thành 1 tam giác thì in ra chu vi của tam giác đó, làm tròn đến 3 chữ số phần thập phân.

## Ví dụ

### Input

```text
3
0 0 0 5 0 199
1 1 1 1 1 1
0 0 0 5 5 0
```

### Output

```text
INVALID
INVALID
17.071
```
